## Priority Issues (four, unpadded)

- [P1] The event that set the level is never named at the point of reading. "A corroborated serious adverse event…" with no object; identifying it takes a scavenger hunt. Fix: muted line under the headline naming the event, deep-linked to its #incident-{id} anchor (exists); backend knows the tripping event. → clarify + small API addition
- [P2] Trend chart reads as escalation while the collector is young: severity-2 data starts Aug 24 inside a 30-day window, ramp with no annotation. Fix: brush-hint caption when first-data < window ("Collection began 24 Aug — earlier days are uncollected, not quiet"). → polish
- [P2] Feed defaults to a media monitor's view (82 rows, majority S1 Analysis) and sev has no visible control — a chip you can remove but never add. Fix: "Events only (severity ≥2)" strip toggle, arguably default-on. → distill
- [P2] Filter strip scope unstated: pressed "30 days" directly under a "Last 7 days" board it doesn't govern. Fix: eyebrow ("Trend, map & feed") or relocate below trend heading. → layout
