## Priority Issues

- [P1] Trend chart hides quiet days (Timeline.tsx:34-45 sparse rows + categorical axis): a 6-day calm gap renders as adjacent bars — manufactured visual escalation; "no data is no data" cuts both ways. Fix: densify axis with zero-count rows. → polish
- [P1] Headline reading can fail silently forever: fetchPosture/fetchSources/boardIncidents .catch(() => {}) never reach noteError (App.tsx:155-157). Fix: route through FAILED_LABEL ("the posture reading", "the collection status"). → harden
- [P2] ▲ means favourable (tone) AND alarm (SAR status, tile levels, stalled banner). Fix: reserve ▲/▼ for tone; distinct alarm glyph for status scale. → polish
- [P2] --text-muted #898781 ≈3.2:1 on light — fails AA at 11-12.5px (day headers, column headers, "no data" lines). Fix: ≈#6f6d67 light; audit dark (~4.1:1). → polish
- [P2] Mobile satellite trench: 48 rows ≈3,000px between trend and feed; Status column beyond unindicated horizontal scroll; .linklike centers multi-line labels. Fix: collapse nominal rows ("46 nominal — show all"), Status next to Site, text-align left. → adapt
