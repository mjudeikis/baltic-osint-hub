## Priority Issues

- [P1] Status colors fail WCAG contrast as text in light theme — including the 28px posture word (PostureBanner.tsx:35). #fab219 on #fcfcfb ≈ 1.8:1; #ec835a ≈ 2.6:1; #0ca30c ≈ 3.3:1. Also .cred-warn, .corrob, tile levels, SAR status. Fix: AA text-tone variants per theme, or level words in --text-primary with color confined to dot + ladder. → polish
- [P1] Initial load renders false data (App.tsx:67-73 initializes to []): tiles read "Quiet / 0 adverse", feed reads "No incidents match" before first response. Fix: null-initialize + muted loading states, extend the posture card's aria-busy pattern. → harden
- [P1] Five-second read answers "unusual?" but not "what should I do?": no path from posture card to Preparedness (5 sections away); posture.typical_week fetched but never rendered. Fix: "How to prepare →" link in the posture card; render "9 adverse · typical week 7". → shape/polish
- [P2] Map contradicts the Fixed Slot Rule (layers.ts): jamming = sabotage-orange while the category is green in charts; thermal red-on-red over territory tint. Fix: separate desaturated instrument family for machine layers. → colorize
- [P2] Feed leads with source-language titles (Feed.tsx:57) on an English-only product; ThreatBoard already uses English summaries for this reason. Fix: summary as scan line, original title as provenance. → clarify

- Sam (a11y): contrast failures top flag; no skip link; drill-through moves view not focus, no aria-live on feed; map pointer-only; hover-only title-attribute disclosures. Good: aria-pressed/current styling, labeled ladder, reduced-motion, severity text flip.
